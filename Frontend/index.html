      Data & Methods

      The data behind Fire Calendar, how the sensors are harmonized, and how the calibration is tested.

      Data sources Harmonization method Calibration results

      Data sources

      NASA FIRMS ↗
      Active fire detections from MODIS Collection 6.1 (1 km) and VIIRS S-NPP (375 m).
      NOAA Climate Prediction Center ↗
      The Oceanic Niño Index used in fire forecasts.
      Map imagery and terrain
      Esri basemap, OpenStreetMap contributors, NASA GIBS Blue Marble imagery, AWS Terrain Tiles (Mapzen Terrarium), and Natural Earth boundaries.

      Harmonization method

      1. Count fire cell-days. Hotspots are placed on a 0.05° grid. Each cell with a fire detection counts once per day, regardless of how many pixels detect it.
      2. Calibrate older observations. For each region, a linear model and a power-law model are fitted using the months when both MODIS and VIIRS observed, from February 2012 through 2025.
      3. Validate across years. Each overlap year is held out in turn. The model with the lower error on held-out years converts the older MODIS counts to the VIIRS scale.
      4. Measure departures from typical activity. Each month is compared with the median for the same calendar month across 2003–2025.
